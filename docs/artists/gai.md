# GAI 周延

**GAI（周延）**，1987 年 3 月 22 日出生于四川省宜宾市珙县，在四川内江威远县长大，重庆说唱代表人物，GOSH 厂牌初代成员，现签约种梦音乐（D.M.G）。十二年酒吧驻唱出身，2017 年获《中国有嘻哈》全国总冠军，此后成为把中文说唱带上主流舞台的标志性人物。代表作《一百零八》《苦行僧》《空城计》《华夏》，个人专辑《光宗耀祖》《烻》《杜康》《Real G》。

GAI，本名周延，1987年3月22日出生于四川省宜宾市珙县。他的父亲是珙县芙蓉煤矿的矿工，周延在矿上长大，有一个学习很好的姐姐周舟。在周延10岁左右，为了让姐姐受到更好的教育（也可能是受到98年大洪水的影响），父母买断工龄，举家搬迁到四川内江市威远县，周延的父亲经营一辆中巴车维持生计（GAI采访说过，如果不做说唱他大概率就要回家开中巴了）。

周延小的时候留着“锅盖头”，便有了个外号——锅盖。刚转学到威远，周延就被校霸霸凌，寻求老师帮助无果后，GAI也就此选择用最原始的方式保护自己：他结交混混，认大哥，打架斗殴，是个名副其实的问题少年，因为打架进过少管所（据说是扎穿了县里某位官员儿子的脚，江湖传说不保真）。初中毕业后，GAI没有书读，但家里要供姐姐上学经济比较拮据，15岁时就把他送去深圳打了半年工。父亲一次去看他的时候发现他过的实在是太惨了，就把他带回来送到重庆永川的水利水电职业技术学院读书（这学校一开始是中专，后来学校自己努力变成了大专），从此重庆这个城市成为了他人生中最重要的一部分。在职校里江湖传言GAI也是刺头，打架斗殴、领着三千学生罢课（不保真，但是肯定没好好上学），但他这时候已经可以在唱歌比赛上为学校争光了，所以职校的生活（应该）没有初中时惨。同时，姐姐以优异的成绩考上了北京的大学。很多年后回顾这段经历，GAI在采访中说，“其实我是装的狠，就是纸老虎，万一绷不住我就惨了。江湖就是比谁胆子大。”职校毕业后，周延被学校分配一所化工厂做扫地工人，但是他没去。

![重庆水利水电职业技术学院毕业留影照片](/images/gai/00-vocational-school-graduation.webp)

![宜宾珙县、内江威远与重庆永川的位置示意图](/images/gai/00-hometown-map.webp)

GAI从小就热爱音乐，喜欢周杰伦、陈小春，曾经在自己的手心用小刀刻上JAY字母，疤痕现在也能看出来，后来还当面给偶像周杰伦展示过。还在上学的时候，他就喜欢说唱、喜欢嘻哈文化。除了主流的周董，他也喜欢很多说唱歌手，这个视频就是早年校园时期他参加校园歌手比赛的画面，唱的是黑棒的《哎呦A-YO》。（[BV1ukuE6fEyQ](https://www.bilibili.com/video/BV1ukuE6fEyQ)）2006年在重庆的百事新星大赛上，他凭一首《霍元甲》拿到了重庆赛区冠军，并开始在重庆的酒吧驻唱生涯。最开始，他一晚上能挣30块钱，后面工资也越来越多，从此驻唱成为他谋生的手段。但因为跟客人发生冲突，他只能辗转在川渝各市县的酒吧谋生（包括永川、自贡、内江、宜宾、铜梁、达州等）。GAI的酒吧驻唱生涯长达12年（一直到参加节目的2017年他仍然在驻唱），这段经历也奠定了他坚实的现场功底。

## 一、前节目时期（2011-2016）

### 2011年：加入厂牌

2011年他在酒吧结识了一位大学生——来酒吧应聘的说唱歌手Tory。当时Tory已经组建了重庆第一个说唱厂牌Keep Real（也就是GOSH的前身），但严格意义上Keep Real不算一个正规的厂牌，它的组织比较松散，只要是玩在一起的，喜欢说唱，会说两句的都可以成为Keep Real的一员。这只属于一种小圈子活动，没有被重庆人知晓。GAI在酒吧驻唱的时候一直在翻唱，但他更想唱自己的歌，因此在Tory的带领下，GAI加入了团体，正式进入说唱领域并加入了Tory的说唱组合Bad Kidz（恶童）。最开始GAI想起小时候的外号“锅盖”而给自己起名Double G，简称D.B.G。后来因为重名，他就把锅盖反过来，想让别人叫他“盖锅”（重庆话谐音盖哥）的意思，GAI由此诞生。

### 2012年：开始发表原创作品

第一首歌D.B.G.虽然略显稚嫩，但是风格上已经初见端倪。彼时所有人都在模仿蛋堡和他的爵士说唱风格，GAI也不例外。在这首歌里，GAI采样了重庆民歌《太阳出来喜洋洋》，从一开始他就有意识地想把中国传统音乐与说唱音乐进行融合，这条融合之路也一直走到现在。

### 2013年：GOSH正式成立

1. 情感经历：GAI有一个相恋7年的女友，19岁开始在一起，这个女友陪他吃了很多年苦，但是到了谈婚论嫁的年纪，GAI还是一无所有，相恋七年后，面对现实两人无奈选择分手（这一段后来在电影《爆裂说唱》中复刻过，呆力呆力人物志里也有提及），甜蜜恋爱时期GAI发布了上面的《Just for cat》，后面GAI为她写过另一首歌《颜如玉》。
2. 早年间GAI活跃在唱吧等翻唱软件中，非常随性的翻唱或改编流行歌曲。在兄弟离世和爱人分手的背景下，他留下了这首“全是感情，没有技巧”的《安河桥》。（如果对其他翻唱作品感兴趣，也可在B站搜索）。
3. GOSH正式成立：2012年Bridge参加了武汉站的IRONMIC battle大赛，获得分站冠军，并且在2013年IRONMIC全国总决赛获得第四名（击败他的是故人P）。这使得KeepReal在说唱圈声名大噪，厂牌众人决定向正规厂牌发展，并于同年7月12日正式更名为GOSH。

### 2014年：音乐风格探索

这一年GAI27岁，在重庆酒吧驻唱为生，穷、苦、脾气冲，但疯狂写歌，为2015年爆发做最后铺垫。14、15年的很多歌曲都收录于后面的mixtape，这里先都列出，收录作品可以酌情先听或者留在16年初的mixtape里一起听。

GAI为了维生，这几年也一直作为歌手去婚礼等场合表演。网络上流传着一段GAI在婚礼上表演的视频，据说报酬是800块，但他从那个时候开始，就满状态的对待每一个舞台，直到现在。

四川内江市威远县的2014春节群众大联欢，来了五六千人。那时他已在酒吧唱了七八年，但还是第一次在父母面前演出。唱完，父母大声跟周围人说，这是我儿子。GAI哭了。

### 2015年：TRAP兴起，崭露头角引爆地下

时年TRAP风行，GAI在跟厂牌的兄弟烧白听伴奏freestyle battle的时候，听到一个TRAP伴奏，随口就唱了一句“老子社会上嘞，老子社会上嘞”，当时正在拉屎的Tory裤子都没提，兴奋地冲出来说：“兄弟，就这个！”（来自《川渝陷阱》的本人描述）然后，经典匪帮说唱《超社会》应运而生。这首歌于2015年4月20日发行，以川渝方言、极端市井叙事描述底层生存逻辑、最阴暗真实的社会乱象。凶狠乖戾的歌词内容只是讲述了一个虚构的故事，并不代表任何人观察、参与过任何其中的活动，类似于犯罪电影中的角色。这首歌一夜刷屏，GAI从此正式拥抱方言说唱。

相比于前两年，2015年GAI的作品质量和数量都有提升，GAI也有一些feat歌曲发布，最经典的是跟贝贝的《只手遮天》还有和TY的《我们的DJ》。另外值得注意的是，可爱女孩这首歌里还有后来的Mandarin乐队主唱Chace朱一涵的参与（这是无论是GAI还是Chace的粉丝可能都不知道的事…）。同年，GAI也招揽了王齐铭和雾都加入GOSH。

### 节目结束后的“红与黑”——签约刘洲、被围攻网暴

（建议观看传记视频2：GAI中篇｜社会主义GAI是怎样炼成的｜GAI不为人知的社会主义化之路 x 深度拉片  [BV18Qu16qEC5](https://www.bilibili.com/video/BV18Qu16qEC5) 剪辑了前半部分，后半部分会在后续的生涯中观看；感谢呆力呆力老师提供原始片源，观众如有兴趣请移步呆力呆力的频道进行观看！）

节目结束后，GAI签约了中国有嘻哈音乐总监刘洲的厂牌DOOR&KEY，开始了他的勇闯主流之旅；同时，他也陷入了另一位冠军引发的第三次哈圈围攻。

**刘洲**是华语流行音乐圈著名的音乐定位制作人、韩红的御用制作人，与很多知名的艺人均有合作，同时也是中国有嘻哈的策划人之一（这里去年有一些话题被重新提及，想吃瓜可以搜李秋泽，不过与主线无关），并且担任节目的音乐总监。当时有嘻哈属于多方合作下的产物，故人K拉来了整个节目的几乎所有商务合同，车澈负责导演（并且为了省钱兼任节目主持），刘洲负责音乐。在节目爆火后，这几个人物都各自开始和自己背后的资本一起酝酿围绕HIPHOP的商业计划，分别招募选手加入。其中，刘洲在节目中期就看中了GAI，并且与GAI等选手签订了经济合同，于节目后组建了音乐公司DOOR&KEY。节目后期，GAI的舞台都有刘洲参与，相比于原来的编曲和呈现都更为完整、更适合线上舞台。刘洲在有嘻哈这个节目里是有一定话语权的，但同时故人P早已签约MDSK，且是故人K的战队成员；由此，很多人也认为最后双冠军的结果是多方角力后都满意的调停方案，当然这也仅仅是网友的猜测（但节目前承诺的冠军奖金只给了GAI一个人）。

刘洲可能是有才华的，但他似乎不懂HIPHOP，一定不懂GAI。当时他疯狂的给GAI接广告歌，每首歌的创作时间都非常有限，并且很多广告歌都是硬广，需要在歌词中直接展示产品的名称和特点，GAI的词作非常受限。不仅如此，刘洲还找来作词人临渡和GAI一起写词，这可能对于流行音乐是正向帮助，但对于HIPHOP来说，GAI无法独立表达自己的所思所想，直接限制了GAI接下来一段时间的作品。

GAI夺冠后火遍全国，但是也充满争议。一方面他积极融入地上、融入主流，而另一方面面对网络上铺天盖地的攻击，他茫然又焦虑。从来没有经历过这种事情GAI的家人也茫然无措地面对着网络上对GAI的赞美与非议，他们既开心又担忧。

GAI夺冠后第二天就在采访中表示，要把奖金全部捐出去（[BV1Ax41177KU](https://www.bilibili.com/video/BV1Ax41177KU)），他也确实这么做了，把100万奖金捐献给了“希望工程快乐音乐教室”项目。在后面的采访中，他说这是投石问路，向迈向主流表达自己的态度，“我只有这一百万，所以我只能成不能败。”

“但是我也相信，我远远不止这一百万。”

接下来他参加了第一档没被剪掉的卫视综艺——蒙面唱将猜猜猜，这个节目让歌手遮住脸去唱歌，让嘉宾去猜他是谁，会在合约满的那一期猜到，因此前面巫启贤、Ella等人就假装猜不到，还有过猜他是郭麒麟的尴尬时刻。其中《爱如潮水》改编自四大名著中的《颜如玉》，全网爆火，GAI也成功为这首下架歌曲留下了第一个地上的版本。

### 2018年10月10日发布首专《光宗耀祖》

### 种梦音乐（D.M.G）

因为刘洲自己糟糕的商业运作能力，他也把自己走到了末路，公司成立以来内部就纷争不断，2018年3月，刘洲因侵占投资人的资金而锒铛入狱，GAI被当做资产抵给了种梦传媒，也就是GAI现在的公司。看起来是一个悲伤的故事，但是福祸相依，这次他遇到了至今为止事业上重要的伙伴。比起刘洲来，种梦的老板韩啸看起来似乎离音乐圈更远。但好在他不插手音乐内的事情，并且也懂得在该撒币的地方撒币，比如在种梦音乐新的北京总部搭建了一个亚洲顶级的录音棚，为旗下艺人提供了良好的创作环境。

不过，种梦传媒最早是影视公司，全公司没有任何音乐产业相关的人，都是拿到GAI的合同后的几年时间里一点一点招进来的。所以在GAI刚刚进入种梦的几年内，仍然没有获得很好的制作条件，公司也更多的安排他去跑音乐节、跑巡演。2018年，GAI开始了世界巡演“大GAI如此·周延世界音乐之旅”，前往港、台、美、加完成了八场演出；2019年，GAI开启了个人首轮国内体育馆级巡回演唱会——《盖·世》，共有上海、广州、南京、武汉、成都、长沙六站。成都站前后，GAI接受了一次采访（采访人有些风波，且时长有40min，正片还是娱乐直播看都行）。（[BV1ea3J6GEsC](https://www.bilibili.com/video/BV1ea3J6GEsC)）

种梦音乐也不断以GAI为原点扩大在嘻哈圈的影响力，不断招揽有实力的rapper加盟，如艾热、Vava、布瑞吉（最开始接下了GOSH的大旗保持地下身份，但是与团队其他成员爆发激烈冲突，后加入DMG）、L4WUDU雾都（新说唱后加入了故人K的厂牌，后来随着故人消失厂牌解散，雾都也加盟种梦）、早安（原厂牌南京freeout飞奥，一首麒麟爆火，后被种梦招入旗下，由种梦和飞奥联合运营）等。在音乐圈，种梦的规模比起其他很多rapper签约的公司来说也就算个小公司，但很多说唱听众认为种梦是“大资本”。

### 我是唱作人2·第二张个人专辑《烻》

**【关于REAL G，先听再看】**

1. Prelude：出门前跟妻子告别（幺幺是GAI对王斯然的爱称），跟司机交代去公司，开启自己的一天。
2. 牌子货outro里的对话内容：
   - GAI：兄弟你认得到是哪个牌子不嘛？
   - Bridge：你依然穿些没得logo的东西，我啷个晓得哎（我怎么知道嘛）。
   - GAI：你摸哈哎（你摸一下）
   - Bridge：摸起我晓得是嫩个回事（摸着我就知道是这么回事）
   - GAI：你再摸哈。
   - Bridge：抻抖，抻抖，（体面，体面），牌子货。
3. 冰红茶：原歌名经制作人透露疑似为《统一》。
4. 钱：采样来自《钞票》，原唱翟惠民。这首歌来自著名囚歌专辑《悔恨的泪》（非常经典的歌词“手里捧着窝窝头，菜里没有一滴油”也来自这张专辑）。《钞票》这首歌跳出《悔恨的泪》专辑其他歌曲的牢狱视角，批判金钱扭曲人性，警示世人不要因财迷失。
5. Break:GAI患有严重的鼻中隔偏曲，常年鼻子不通气，打呼噜，歪嘴也和这个病有关。但因为担心影响发声方法无法再唱歌，他一直没有做手术。不过这首“歌”已经无法再“唱”了，26年初应该是找到了安全的术式，GAI终于做了这个手术，再也不打呼噜了。
6. 赢:Outro截取采样的是1998 年电影《荆轲刺秦王》片中李雪健饰演的嬴政暴怒嘶吼的名场面。嬴政刺死荆轲后，癫狂地怒斥满朝文武：“寡人不让你们上来，你们居然没有一个人出来拦住刺客！出去！”
7. 星梦:女声吟唱是GAI自己唱的，然后变调处理。采样来自纪录片《归途列车》，纪录了春运里一个四川农民工家庭的三年实录。和GAI一样，纪录片中的女孩也是很小就出门打工。
8. 华佗:采样了两段94年版电视剧《三国演义》的原声，开头是华佗为关羽刮骨疗毒的对话，中间是华佗为曹操治病的对话。
