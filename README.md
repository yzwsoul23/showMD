# 中文说唱档案

> 静态 Markdown 档案阅读器，个人前端练手项目

## 项目介绍

本项目是一个静态网页版 Markdown 阅读器，用作中文说唱档案展示站点。纯静态页面，无需后端，用来浏览、查阅 rapper 相关档案文稿。

## 功能特性

- ✅ Markdown 文档完整渲染
- ✅ 自动生成文档目录，支持锚点跳转
- ✅ 内置 9 套阅读主题，可一键切换样式
- ✅ 轻量化静态部署，开箱即用
